# 프로토타입 실행법

설문에 답하면 추천 운동이 나오는 것까지만 확인하는 화면입니다.
**디자인 없음 · 시설(지도) 검색 없음 · 저장 없음.**

```
python prototype/app.py
```

브라우저가 자동으로 열립니다. 안 열리면 http://localhost:8000 으로 접속하세요.
끄기는 터미널에서 Ctrl+C 입니다.

- 설치할 것 없습니다. 파이썬 표준 라이브러리 + numpy(배정 계산)만 씁니다.
- 브라우저를 띄우지 않으려면 `python prototype/app.py --no-browser`
- 같은 네트워크의 다른 사람도 볼 수 있습니다 — 실행한 PC의 IP로 `http://<IP>:8000`

## 보시면 좋을 것

| 넣어볼 값 | 확인할 점 |
|---|---|
| 나이 34 / 나이 72 | 체력 자가평가 문항이 바뀝니다 (65세 기준, 성인은 근지구력·순발력 / 노인은 하지근기능·협응력) |
| 불편 부위 '무릎' 체크 | 무릎 부담 종목이 **제외** 칸으로 빠집니다. 우리가 판정하는 게 아니라 사용자가 고른 것을 빼는 방식입니다 |
| 같은 답 + 체력 자가평가만 낮게 | 종목은 그대로인데 **권장 강도 상한과 보완 운동이 바뀝니다.** 체력축은 종목 선택에 관여하지 않습니다 |
| '자주 해온 운동' 체크 / 안 함 | 추천이 **익숙한 운동 / 새로운 운동** 두 갈래로 갈립니다 |
| 규칙적 운동 '아니오' | 선호 유형을 배정하지 않고 관심 종목만으로 추천합니다 |
| 나이 16 | 체력 유형을 배정하지 않습니다 (측정 원자료에 없는 연령) |

결과 화면 맨 아래 **"개발용 — 원본 응답 / 출력 JSON"** 을 펼치면 앱이 실제로 받게 될
JSON 전체가 보입니다. 시설 검색 조건도 거기에 들어 있습니다(화면에는 표시하지 않음).

## 알아두실 것

- **체력 유형은 정확도 50% 내외입니다.** 자가평가로 실측을 대신하기 때문이고, 확신도가
  낮으면 대안 유형이 함께 표시됩니다. 단정적으로 읽지 마세요.
- 점수 숫자는 **같은 응답 안에서만 비교되는 상대값**입니다. 실제 앱에서는 노출하지 않습니다.
- 선택지 문자열은 이 파일에 적어 둔 것이 아니라 `assignment/params/preference_model.json`
  에서 그대로 읽어 옵니다. 설문 선택지와 모델 범주가 어긋나는 사고를 막기 위한 구조입니다.
