# UI 개편 프롬프트 — Grab 스타일 적용

> `web/ui` (React + TS + CSS Modules) 대상. 레퍼런스: Grab 앱 4화면(홈 / 스플래시 / 차량선택 / 라이드 랜딩).
> 아래를 그대로 복사해 코딩 에이전트에게 전달한다.

---

## 프롬프트 본문

`web/ui`의 디자인을 Grab 앱의 시각 언어로 개편해라. **기능·데이터·문구는 그대로 두고 외형만 바꾼다.**

### 0. 먼저 읽을 것

- `src/styles/tokens.css` — 토큰과 그 결정 근거(주석)
- `src/styles/base.css`, `src/styles/controls.css` — 전역 타이포·버튼·카드
- `src/components/*.module.css` — TopBar / TabBar / Hero / SportTile / Rail
- `src/screens/Home.tsx`, `Result.tsx`, `MapScreen.tsx`, `Records.tsx`, `Intro.tsx`
- `docs/앱구현_PRD.md` §11(노출 금지 항목), §4(로컬 저장 고지)

### 1. 절대 제약 — 어길 경우 개편 실패로 본다

1. **본문 17px, 터치 타깃 48px 하한을 낮추지 마라.** 노인 사용자가 주요 대상이다. 레퍼런스의 13~14px 라벨을 그대로 옮기지 말 것.
2. **다크 모드를 추가하지 마라.** `prefers-color-scheme` 분기 금지. 심사장 기기 설정에 따라 화면이 달라지면 안 된다(tokens.css 주석 참조).
3. **웹폰트를 새로 불러오지 마라.** 오프라인 시연 전제. Grab 특유의 둥근 산세리프 느낌은 폰트가 아니라 **굵기(700~800)와 라운드**로 낸다.
4. `src/api/`, `src/state/`, `src/features/`, `src/lib/` 는 건드리지 마라. 변경은 `src/styles/`, `src/components/`, `src/screens/` 의 마크업·CSS에 한정한다.
5. **점수·확률·순위 수치를 화면에 노출하지 마라**(PRD §11). 기존에 감춰진 값을 디자인 목적으로 꺼내지 말 것.
6. 사용자에게 보이는 **한국어 문구를 임의로 고치지 마라.** 레이아웃상 불가피하면 먼저 물어라.
7. `prefers-reduced-motion` 블록과 `:focus-visible` 아웃라인을 유지해라.

### 2. 레퍼런스에서 가져올 시각 원칙 10가지

1. **컬러 밴드 + 흰 캔버스** — 화면 상단은 채도 높은 색 밴드, 그 아래는 흰 배경. 회색 페이지 배경을 쓰지 않는다.
2. **그린 3단 위계** — 딥그린(앱바·배지) / 브랜드 그린(CTA·활성 상태·선택 테두리) / 라임(감성 밴드 배경).
3. **파스텔은 카드 배경 전용** — 블루=정보·안내, 피치·버터=보조 카테고리. 글자색으로는 절대 쓰지 않는다. 카드 위 글자는 언제나 `--ink`.
4. **라운드 3단** — 필(999px): 입력·버튼·칩 / 16~24px: 카드·바텀시트 / 원형: 플로팅 버튼·아바타.
5. **그림자 최소화** — 카드는 1px 보더나 파스텔 채움으로 분리한다. 그림자는 **지도 위에 떠 있는 것**(플로팅 버튼, 바텀시트)에만.
6. **크기가 아니라 굵기로 위계** — 값·제목 700~800 진한 잉크, 라벨·메타 400~500 회색.
7. **상태는 채움이 아니라 테두리·틴트** — 선택된 항목은 배경 흰색 유지 + 초록 1.5px 테두리. 활성 탭은 아이콘 채움 + 초록 라벨.
8. **가장자리로 흘리기(bleed·peek)** — 가로 레일은 오른쪽 화면 끝에서 잘리게 두고, 카드 일러스트는 카드 밖으로 삐져나가게 자른다.
9. **주 버튼 + 위성 버튼** — 풀폭 초록 필 CTA 왼쪽에 원형 아이콘 버튼을 붙이는 하단 액션 패턴.
10. **복합 입력** — 큰 필 안에 좌측 아이콘 + 우측 보조 액션 칩을 넣는다.

### 3. 토큰 변경 (`src/styles/tokens.css`)

기존 변수 이름을 바꾸지 말고 **값 조정 + 신규 추가**로 처리해라. 추가한 토큰마다 왜 필요한지 한 줄 주석을 붙여라(파일의 기존 문체를 따를 것).

- `--accent`: `#1db954` → `#00b14f` (딥그린과의 3단 위계가 선명해진다). `--accent-ink`(`#0b7a37`)는 대비 확보용이므로 유지.
- 신규 `--brand-deep: #0b5c39` — 앱바 밴드·강조 배지.
- 신규 `--brand-lime: #d9f26b` — 홈 상단 밴드. 이 위의 글자는 반드시 `--ink`.
- 신규 `--tint-blue: #dff0fb`, `--tint-peach: #ffe2cf`, `--tint-butter: #fff3c4` — 안내·프로모 카드 배경 전용.
- 신규 `--radius-pill: 999px`, `--radius-sheet: 24px`.
- `--shadow`의 용도를 축소하고 신규 `--shadow-float: 0 4px 16px rgba(13,17,23,.16)` 를 추가 — 지도 위 플로팅 요소 전용.
- `--tabbar-h`는 탭바 높이 변경(아래 4-7)에 맞춰 함께 조정해라.

### 4. 화면·컴포넌트별 지시

**4-1. TopBar** — 흰 반투명 sticky 바를 **딥그린 밴드**로 바꾼다. 브랜드 워드마크는 흰색, 지역 칩은 흰 배경 필. 상태바 영역까지 색이 차도록 `env(safe-area-inset-top)` 만큼 상단 패딩을 준다. sticky 동작과 `--page-max` 폭 제한은 유지.

**4-2. Home 상단** — 앱바 아래에 `--brand-lime` 밴드를 두고 **하단 경계를 곡선(웨이브)** 으로 처리한다(레퍼런스 4번). 밴드 안에 날짜·인사말(`오늘도 움직여 볼까요`)과 EnvBar를 넣되, EnvBar는 밴드 위에 얹은 **흰 필 카드**로 만들고 `지역 변경` 은 우측 보조 칩으로 붙인다(원칙 10). 밴드는 좌우 여백을 무시하고 화면 끝까지 찬다.

**4-3. Hero** — 무지개 그라데이션(`#12b04f → #0f9d84 → #0b7ea8`)을 **딥그린 단일 계열**로 정리해 그린 3단 체계를 깨지 않게 한다. `ambiguous`일 때의 대안 유형 줄은 반드시 남긴다.

**4-4. Rail / SportTile** — 레일은 이미 화면 끝까지 흐르므로(`margin: 0 -16px`) 구조를 유지하되, 아래에 **페이지 인디케이터**(활성 = 긴 바, 비활성 = 점)를 추가한다. 레퍼런스는 인디케이터가 작지만 여기서는 높이 6px 이상으로 키워라. 캡션 14px → 15px. 커버 그라데이션은 유지.

**4-5. Result(운동 탭) 종목 목록** — 레퍼런스 차량 선택 행 패턴으로 바꾼다: `좌측 썸네일(커버) · 제목 굵게 · 메타 회색 한 줄 · 속성 칩 · 우측 셰브론`. 속성 칩은 두 종류로 구분한다 — 연녹 채움(권장·오늘 추천), 연회색 아웃라인(강도·실내외). 선택 시 행 전체를 초록 1.5px 테두리로 감싼다.

**4-6. MapScreen** — 지도 + 바텀시트 구조로 재구성한다.
- 지도 캔버스를 상단 약 55% 높이로 키우고 좌우 여백 없이 화면 끝까지 채운다.
- 종목 칩(`.chips .opt`)은 지도 **위에 떠 있는 가로 스크롤 줄**로 옮기고 `--shadow-float` 를 준다.
- 시설 목록은 상단 라운드 `--radius-sheet` + 회색 핸들 바를 가진 **바텀시트**로 감싼다.
- 시설 행: `아이콘 · 이름 굵게 · 거리/혼잡 메타 회색 · 예약 가능 칩`.
- 시트 하단에 sticky 액션 영역 — 풀폭 초록 필 CTA + 좌측 원형 위성 버튼(원칙 9).
- Leaflet 타일 실패 시 대체 화면(`tileFailed`) 처리는 그대로 살려라.

**4-7. TabBar** — 활성 탭은 **아이콘 채움 + 초록 라벨**, 비활성은 아웃라인 회색. 라벨 12px → 14px, 최소 높이 62px → 68px(`--tabbar-h` 동반 수정). 빨간 점 배지를 붙일 수 있는 슬롯을 마련해라(지금은 미사용).

**4-8. Records** — 링 카드 배경을 `--accent-soft`로 채워 이번 주 성과를 시각적으로 분리한다. 요일 막대는 `--accent` 유지. 기록 행은 4-5의 행 패턴과 통일한다. `기록은 이 기기에만 저장됩니다` 고지는 `--tint-blue` 안내 카드로 승격하되 문구는 그대로.

**4-9. Intro / 스플래시** — 진입 화면을 브랜드 그린 전면 + 중앙 워드마크로 만든다(레퍼런스 2번). 스피너를 넣지 말고 짧게 지나가게 한다.

**4-10. Survey** — `.opt` 의 선택 표현(초록 테두리 + `--accent-soft`)이 이미 레퍼런스와 같은 원리다. **구조를 바꾸지 말고** 라운드·간격만 새 토큰에 맞춰라.

### 5. 레퍼런스에서 가져오면 안 되는 것

- **말줄임(…)** — 레퍼런스는 한 줄로 자르지만, 여기서는 리스트 부제를 2줄까지 허용하고(`-webkit-line-clamp: 2`) 그래도 넘칠 때만 자른다.
- **13~14px 소형 라벨** — 최소 15px. 탭바 라벨은 14px.
- **3D 클레이 일러스트** — 자산 제작 비용이 크다. 파스텔 카드 배경 + 기존 그라데이션 커버로 대체하고, 새 이미지 파일을 만들지 마라.
- **파스텔 다색 카테고리 코딩** — 강도·종목에 색을 배정하지 마라. 기존 `.badge` 의미 체계(`warn`/`env`/`res`)와 충돌한다. 파스텔은 프로모·안내 카드에만.
- **peek 잘림만으로 스크롤을 알리는 방식** — 잘림은 유지하되 인디케이터를 반드시 함께 둔다.

### 6. 작업 순서

`tokens.css` → `base.css`/`controls.css` → TopBar/TabBar → Home → Result → MapScreen → Records → Intro. **각 단계마다 `npm run build` 를 통과시키고 다음으로 넘어가라.**
