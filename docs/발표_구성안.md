## S4 · 선호축 — 파라미터로 사후확률을 계산

```

```

```

```

**슬라이드 텍스트**

**🖼 화면** — 왼쪽 5축 레이더(사용자 한 명), 오른쪽 2D 산점에 중심 4개 + 최근접 화살표


# 부록 (넘기지 않음)

## A1 · 체력축을 왜 자가평가로 받는가

- 라이브 사용자는 국민체력100 측정을 받지 않는다
- 키·몸무게 회귀 프록시는 실측 R² **0.07 ~ 0.38**로 폐기
  - 원인: z-score가 이미 연령대 × 성별 내부 표준화라 나이·성별 정보가 제거됨
- 신체조성 축만 회귀 유지 (R² 0.50 ~ 0.58)
- 5단계 응답 — 3단계보다 천장이 높다 (77.6% → 82.5%)
- 4개 유형은 자연 군집이 아니다 (실루엣 k=2 최고) → **개인에게 단정하지 않는 이유**

## A2 · 추천 재현율 — 평가 방법

- 6,602명 전원 **5-fold 교차검증**, out-of-fold 평가
- 배정된 유형의 top-3 안에 실제 신고 종목이 있는지

| 세그먼트 | N | 유형기반 | 인기도 | 무작위 |
|---|---|---|---|---|
| 노인 남성 | 905 | 75.9% | 74.8% | 16.7% |
| 노인 여성 | 966 | 85.3% | 82.9% | 16.7% |
| 성인 남성 | 2,252 | 67.2% | 60.5% | 11.5% |
| 성인 여성 | 2,150 | 73.6% | 71.4% | 11.1% |
| **가중평균** | **6,273** | **73.4%** | **69.7%** | **12.9%** |

- 한계: 설문의 주 참여 종목이지 앱 클릭·수락률이 아니다. 안전 필터·강도는 미포함

## A3 · 체력축 정확도 천장

| | 성인 남 | 성인 여 | 노인 남 | 노인 여 |
|---|---|---|---|---|
| r = 1.0 (천장) | 77.6% | 75.2% | 76.7% | 75.2% |
| r = 0.7 | 57.5% | 57.7% | 57.4% | 59.5% |
| r = 0.5 | 48.1% | 49.7% | 49.8% | 52.1% |
| 찍기 | 32.0% | 28.6% | 28.5% | 33.4% |

- r은 현재 데이터로 측정 불가 → 출시 후 간이 측정 병행이 유일한 검증 경로
- 확신도 1.2 미만이면 대안 유형 병기 (배정 모호 30.2%)
