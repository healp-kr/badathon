**2026-08-07 · 근거: `분류알고리즘_사양.md`**

이 설문은 두 가지를 배정한다.

- **선호 유형 12개** — §2의 6문항이 LCA 형성변수와 **범주까지 정확히 일치**해야 한다. 범주를 하나라도
  바꾸거나 빼면 학습된 조건부 응답확률과 매칭되지 않는다. §2는 임의로 수정하지 말 것.
- **체력 유형 16개** — §4의 자가평가를 분위 매핑으로 z-score에 대응시켜 배정한다. 정확도는
  자가평가 신뢰도에 달려 있고 현재 기대치는 50% 내외다(§6 참조).

문항 수: 필수 **13문항** (선호 6 + 체력 4~5 + 기본 3~4). 소요 2~3분.

## §4. 체력 자가평가 (성인 4문항 / 노인 4문항)

**모든 문항을 "같은 나이·성별의 또래와 비교해서"로 물어야 한다.** 체력 z-score가 연령대×성별 셀
내부 표준화 값이라, 절대적 자기평가를 받으면 분위 매핑이 성립하지 않는다.

**5단계 척도 공통**: 매우 낮은 편 / 낮은 편 / 보통 / 높은 편 / 매우 높은 편

### 공통 (성인·노인)

- **Q13 (근력)** — 무거운 물건을 들거나 힘을 쓸 때, 또래와 비교해 힘이 센 편인가요?
- **Q14 (유연성)** — 앉아서 상체를 앞으로 굽힐 때, 또래보다 유연한 편인가요?

### 성인 트랙 (19~64세)

- **Q15 (근지구력)** — 윗몸일으키기처럼 **같은 동작을 반복**할 때, 또래보다 오래 지속할 수 있나요?
- **Q16 (순발력)** — 제자리에서 멀리 뛰거나 순간적으로 튀어나갈 때, 또래보다 잘하는 편인가요?

### 노인 트랙 (65세 이상)

- **Q15' (하지근기능)** — 의자에 앉았다 일어서기를 반복할 때, 또래보다 수월한 편인가요?
- **Q16' (협응력·평형)** — 걷다가 방향을 바꾸거나 한 발로 설 때, 또래보다 균형을 잘 잡나요?

> **분기 기준이 §2(선호)와 다르다. 여기는 65세다.** 체력 모델은 측정 프로토콜대로
> 성인 19–64 / 노인 65+ 로 적합됐고, 축 구성 자체가 다르다. 60–64세에게 노인 문항을 물으면
> 배정할 모델이 없다. 표시 라벨만 60+ = 노인이다.
>
> | | 선호 모델 | 체력 문항·모델 | 표시 라벨 |
> |---|---|---|---|
> | 노인 경계 | **60세** | **65세** | **60세** |

### 초안에서 바뀐 점

| 초안 | v1 | 이유 |
|---|---|---|
| 3단계 (저/중/고) | **5단계** | 이산화 손실. 천장이 77.6% → 82.5%로 상승 |
| "심폐지구력" | **근지구력**으로 문구 변경 | 성인 축은 교차윗몸일으키기 기반이다. 심폐지구력에 대응하는 축이 없다 |

| 노인용 문항 없음 | **하지근기능·평형 추가** | 노인 축은 성인과 다르다. 이 둘이 없으면 완벽 가정에서도 **50%**에 그친다 |
| 신체조성 자가평가 | **삭제**, 키·몸무게로 대체 | 회귀 R²=0.50~0.58로 자가평가보다 정확하고, 이미 받는 정보다 |

## §5. 분위 매핑 구현 규칙

1. 각 축의 응답을 **누적 응답 비율의 구간 중앙에 해당하는 z**로 변환한다.
   응답 분포가 "보통"에 몰리므로 균등 5분위를 가정하면 안 된다.
   → `z = Φ⁻¹((F_below + F_here/2))`, F는 앱 사용자 응답의 누적 비율.
   초기에는 정규 5분위 대표값(-1.40, -0.52, 0, +0.52, +1.40)으로 시작하고,
   응답이 쌓이면 실제 분포로 교체한다.
2. **신체조성 축**은 자가평가가 아니라 키·몸무게·BMI 회귀로 추정한 값을 넣는다.
3. 5축 벡터를 하위집단별 K-means 중심에 **최근접 배정**한다. 중심은
   `fit2023_segments_final_v2.csv`에서 (하위집단, 체력세그먼트)별 z축 평균으로 복원된다.
4. **배정확신도 = (2번째 가까운 중심 거리)/(가장 가까운 중심 거리)**. **1.2 미만이면 모호**로 보고
   단정적 라벨 대신 대안 세그먼트나 종합 수준으로 대체한다.

## §6. 이 설계의 한계 — 반드시 함께 인지할 것

- **체력 유형 정확도 기대치는 50% 내외다.** 자가평가가 완벽하다면 75~78%, 신뢰도 r=0.7이면
  57~60%, r=0.5면 48~52%다(최빈 클래스 찍기 = 28.6~33.4%).
- **r은 현재 데이터로 측정할 수 없다.** 국민체력측정 데이터에는 자기보고 문항이 하나도 없다.
  → **출시 후 검증 루프 필수**: 일부 사용자에게 자가평가와 함께 간이 측정(30초 의자 일어서기,
  앉아윗몸앞으로굽히기)을 받아 r을 추정하고 매핑을 보정한다. 이것이 유일한 검증 경로다.
- **전반적 우수형 ↔ 전반적 저조형 혼동이 가장 위험하다.** 중위 두 유형 간 혼동은 처방 차이가
  작아 감수할 수 있지만, 극단 혼동은 안전 문제다. 확신도 게이트를 반드시 적용할 것.
- 선호 유형은 6문항을 모두 받으므로 **posterior가 정확히 계산된다.** 이쪽은 정확도 이슈가 없다.
  다만 하드 라벨 하나만 쓰지 말고 2순위 유형까지 활용할 것.

> **추가 권장(모델 입력 아님)**: 운동 처방을 내보내는 서비스이므로 부상 이력·만성질환·의사 운동
> 제한 여부에 대한 안전 스크리닝 문항을 별도로 두는 것을 권한다.
