## D. 선호축 파라미터 (LCA)

**분류기를 새로 학습하지 않는다.** LCA는 생성모형이라 사전확률·조건부 응답확률만으로
임의 응답의 posterior를 직접 계산한다.

```
log P(class c | x) ∝ log π_c + Σ_j log θ_{j,c,x_j}
```

- 파라미터 파일: `assignment/params/preference_model.json` (원천 `07_lca_parameters.csv`)
- 형성변수 6개 = 운동빈도(8) · 운동요일(3) · 운동시간대(6) · 운동목적(11) · 운동강도(3) · 체력인지(5)
- 응답이 없거나 levels에 없는 항목은 **주변화**(해당 항 스킵)
- 출력은 하드 라벨 + `probability`, **2순위(`runner_up`) 병기**

## E. 체력축 파라미터 (자가평가 분위 매핑)

### 왜 회귀 프록시를 폐기했는가 — 실측 R²

국민체력측정 데이터에 자기보고 문항이 하나도 없어 자가평가↔실측 학습이 불가능.
공유 변수는 나이·성별·키·몸무게뿐인데, z-score가 이미 연령대×성별 표준화라 나이·성별 정보는 제거돼 있다.

| | 성인 남 | 성인 여 | 노인 남 | 노인 여 |
|---|---|---|---|---|
| PC1 (종합 체력수준) ~ 키·몸무게·BMI·연령 | 0.14 | 0.11 | 0.07 | 0.14 |
| PC2 (체성분 vs 기능) ~ 동일 | 0.14 | 0.16 | 0.34 | 0.38 |

### 5축 구성 (성인·노인이 다르다)

| 축 | 성인 원변수 | 노인 원변수 | 방향 |
|---|---|---|---|
| 근력 | 절대악력(**체중 잔차화**) | 좌동 | 높을수록 좋음 |
| 근지구력 | 교차윗몸일으키기(회) | — | 높을수록 좋음 |
| 순발력 | 제자리 멀리뛰기(cm) | — | 높을수록 좋음 |
| 하지근기능 | — | 의자에 앉았다 일어서기(회) | 높을수록 좋음 |
| 협응력·동적평형 | — | 의자에 앉아 3M 표적 돌아오기(초) | **낮을수록 좋음 (부호 반전)** |
| 유연성 | 앉아윗몸앞으로굽히기(cm) | 좌동 | 높을수록 좋음 |
| 신체조성 | 체지방율(%) | 좌동 | **낮을수록 좋음 (부호 반전)** |

- z-score는 **연령대(5년 구간) × 성별 셀 내부** 산출 = 모든 값이 '동년배 대비'
- **악력 체중 잔차화 근거**: 상대악력(절대악력/체중) 사용 시 근력–신체조성 상관 **.50~.59** → 잔차화 후 **.25~.34**
- 5축은 재표준화로 동일 가중

### 5단계 응답 → z 매핑 (`level_to_z`)

초기 시작값 = 정규 5분위 대표값 **(-1.40, -0.52, 0, +0.52, +1.40)**
일반식: **z = Φ⁻¹(F_below + F_here/2)** — 응답이 '보통'에 몰리므로 균등 5분위 가정 금지.

### 지표 정의

| 지표 | 정의 |
|---|---|
| HR@K | top-K 안에 1순위 신고 종목이 있으면 1 |

## J. 환경 컨텍스트 · GIS 파라미터

### 날씨·대기·자외선 판정 임계값

| 항목 | 임계값 | 판정 |
|---|---|---|
| 강수 (PTY ≠ 0) | 비 · 비/눈 · 눈 · 소나기 예보 | **비권장** |
| 기온 | **≥ 33도** | 주의 |
| 기온 | **≤ -12도** | 주의 |
| 통합대기환경지수(CAI) | 등급 **4** (매우나쁨) | **비권장** |
| CAI | 등급 **3** (나쁨) | 주의 |
| 자외선 지수 | **≥ 6** ('높음' 구간 시작) | 주의 (낮 시간대에만 배지 노출) |

- 캐시 TTL **600초(10분)** — 초단기예보는 매시 30분 발표, 45분 이후 호출 가능
- 격자: 중구 nx **60** / ny **127**, 관악구 nx **59** / ny **125**
- 판정 우선순위: 모름 0 < 정상 1 < 주의 2 < 비권장 3 (**큰 쪽이 이긴다**)
- 낮 시간대 정의: 아침·새벽(6-8) / 오전(8-12) / 점심(12-14) / 오후(14-18)

**재정렬 원칙 3가지**
① 종목을 지우지 않는다 — 순서만 바꾸고 이유를 배지로 말한다
② 갈래(기반/익숙한/새로운) 경계를 넘어 섞지 않는다 — 두 갈래의 클릭률 비교가 가중치 보정의 근거
③ 모르면 아무것도 하지 않는다 — 조회 실패는 '정상'이 아니라 '모름'

> `serve()`는 건드리지 않는다. **같은 입력이면 항상 같은 출력**이라는 성질이 로그 분석과
> `model_version` 추적의 근거다. 날씨는 표현 계층 후처리로만 적용한다.
> `serve(payload, top_n=10)`으로 넉넉히 받고 `apply_context(..., display_n=3)`이 **재정렬 뒤에** 자른다.
> `top_n` 기본값(3)이면 야외형 사용자는 상위 3개가 전부 실외라 끌어올릴 실내 종목이 없다.

| 체력 군집의 자연성 | 실루엣 k=2가 최고(0.25~0.28), k=4는 0.17~0.19 |

| MET 미확인 종목 | **11종** (추천가능 6종 포함) |
| 강도 라벨 편향 | '저' 강도가 **1종목뿐**. 대표값을 '열심히 하는 버전'으로 골랐다 |
| 근거 없는 파라미터 | 점수 가중치 전반, 종목별 부담부위 태깅, 고령 비권장 태깅, 순발력 보완 운동 |
| 19세 미만 | 체력 유형 미배정 (측정 원자료에 해당 연령 없음) |
| 비참여자 | 선호 모델 밖 분기 — 배정할 클래스가 존재하지 않음 |

**소급 수집이 불가능한 것** — 로그를 v1부터 남기지 않으면 영원히 모른다:
① 체력 자가평가 신뢰도 **r** ② 근거 없이 정한 가중치들이 맞는지.

**화면 문구에 반영할 것**
- 단정적 표현 금지 ("당신은 저조형입니다" → `ambiguous: true`면 `alternative` 병기)
- **추천 근거는 인과가 아니다** — "비슷한 분들이 많이 하십니다"는 그들이 이미 하는 것이지
  그들에게 좋은 것이 아니다. "추천"보다 "비슷한 분들의 선택"이 정확한 표현
- 강도는 절대값(심박수·중량)이 아니라 **상대 표현**으로 ("지금보다 조금 가볍게")
- 보완 운동은 처방이 아니라 **제안**으로 표현
- 강도 라벨은 "세게 하면 고강도"라는 뉘앙스로 표기
- `점수`는 같은 응답 안에서만 비교 가능한 상대값 — **사용자에게 숫자로 노출하지 말 것**
