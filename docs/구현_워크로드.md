**B5는 더 이상 의학 판단이 아니다.** "무릎 통증에 등산 금지"를 우리가 판정하지 않고, 사용자가
불편한 부위를 고르면 해당 태그 종목을 숨긴다. 판단 주체가 사용자로 옮겨간다.

**근거 없이 남는 것** (구현하되 "제안"으로 표현, 전문가 확보 시 1순위 검토):
순발력 보완 운동 / 종목별 부위 부담 태깅 / 26종목 MET / w₁ 내부 결합 비중.

**B2에서 결정할 것**: 선호점수비율(그 클래스가 실제로 많이 하는 종목)과 Lift(그 클래스에서
유독 튀는 종목)를 어떻게 섞을지. 전자만 쓰면 전부 "걷기"가 1등이 되고, 후자만 쓰면 소수 종목이
과대 추천된다. **기본값: 점수비율 0.7 + Lift 0.3으로 시작해 B7에서 눈으로 조정.**

**추천 파이프라인 (두 축을 저울질하지 않고 순서대로 적용)**

```
① 종목 후보      ← 선호축만 (w₁, 데이터 기반)
② 두 갈래로 분기  ← 사용자가 고른 종목 / 고르지 않은 종목
③ 안전 필터       ← 부상·연령·강도 상한 (하드 컷, 점수 무시)
④ 강도·빈도 조절  ← 체력축 (B4)
⑤ 보완 운동 1~2개 ← 체력축 약한 부위 (B3)
```

**②는 2026-08-07 추가.** 추천을 **익숙한 운동**(사용자가 Q11·Q12에서 고른 종목)과
**새로운 운동**(고르지 않은 종목 중 같은 유형에서 적합도가 높은 것)으로 나눈다.

- 개인 응답이 추천에 실제로 반영된다 — 그 전에는 같은 유형이면 누구에게나 같은 결과였다
- 걷기 편중이 완화된다. 걷기를 고른 사용자는 걷기가 익숙한 쪽으로 빠지고 새로운 쪽에 다른 종목이 올라온다
- **비참여자 분기(C4)가 여기서 해결된다.** 선호 유형이 없어도 관심 종목만으로 익숙한 갈래가 성립한다
- 두 갈래의 클릭률을 비교하면 w₁의 유효성을 측정할 수 있다 → D4 가중치 보정의 근거

## 크리티컬 패스

```
A (2~3일, 독립)  ─────────────┐
                              ├─→ B6 추천 함수 → B7 검수 → C 연동 → 출시
B1·B2 (1일) ─┐                │
B3·B4·B5 초안 ─→ 도메인 검토 ─┘   ← 여기가 병목
```

**착수 순서**

1. **B3·B4·B5 초안을 먼저 만들어 도메인 검토자에게 넘긴다** (검토 대기 시간을 벌기 위해)
2. 그 사이 A 전체를 완성한다
3. B1·B2 → B6
4. 도메인 피드백 반영 → B7 48셀 검수
5. C 연동, D1 로그 스키마는 C와 동시에

**지금 막혀 있는 것 2가지**

- **도메인 검토자 확보** (체육 전공자). B3~B5·B7이 여기 걸린다
- **설문 문항 확정** (C1). 확정 전에 C2·C3를 시작하면 재작업이 생긴다

마찬가지다. 일정을 결정하는 것은 아래 네 가지뿐이다.
