# 평가 방법 1-c — 격차의 유의성 (대응표본 부트스트랩)

**읽는 법**: CI가 0을 걸치면 그 격차는 이 표본으로는 방향을 말할 수 없다. n이 크면 작은 차이도 유의하게 나오므로, **유의성과 크기를 따로 읽어야 한다.**

## 한계

- 폴드 재적합 변동은 이 CI에 포함되지 않는다 (폴드는 5개로 고정).
- 한 세그먼트 안의 응답자들은 같은 순위표 몇 개(클래스 수만큼)를 공유하므로 완전한 독립 표본이 아니다. CI는 실제보다 다소 좁게(낙관적으로) 나온다.
