# 종목 강도 라벨 재검토

**2026-08-13 · 대상: `recommendation/data/sport_master.csv`의 `강도` 컬럼**

강도가 전반적으로 높게 잡혀 있다는 지적에서 출발했다. 원인을 셋으로 갈랐고 **둘은 코드에서
고쳤다(A·B).** 이 문서는 남은 하나 — **대표 MET 값 선택 자체가 높다** — 에 대한 검토표다.

---

## 1. 무엇을 고쳤고 무엇이 남았는가

| | 문제 | 상태 |
|---|---|---|
| **A** | 배정이 **모호하다는 이유만으로** 강도 상한이 내려감 | **수정 완료** — `_prescribe()`에서 제거 |
| **B** | 상한 초과 종목을 **삭제**함 (하드 컷) | **수정 완료** — 점수 감산(×0.6) + `강도주의` 배지로 변경. 하드 컷은 노인+전반적 저조형+배정 확정에서만 |
| **C** | 대표 MET을 **"열심히 하는 버전"** 으로 고름 | **이 문서. 사용자 확인 필요** |

### A·B의 효과 (자가평가 2,500조합 전수)

| 지표 | 수정 전 | 수정 후 |
|---|---|---|
| 상한이 '고'가 아닌 사용자 | **50.2%** | **5.8%** |
| 그중 실제로 체력이 낮아서 | 2.4% | 5.8% (전부) |
| 상한 '저' (추천이 1~2종목으로 붕괴) | 3.4% | **0%** |
| 강도 사유 제외 종목 (평균) | 여러 종목 | **0.04종** |
| 제외 칸 ↔ 보완운동 칸 **모순** | **56건** | **0건** |
| 새로운 운동 0건 | 있음 | **0건** |

> **"맨 뒤로 보내기"는 삭제와 같다.** 처음엔 강등 항목을 목록 끝에 붙였는데, 갈래당 3개만
> 표시하므로 배지가 **한 번도 노출되지 않았다**. 그래서 점수를 ×0.6 하고 정렬에 맡기는 방식으로
> 바꿨다 — 적합도가 뚜렷이 높은 종목은 배지를 달고 살아남는다.
> (검증: 고강도 선호 사용자 중 상한이 '중'인 97건에서 **37건이 배지를 달고 노출**. 예: 70세 여,
> 등산이 '고'지만 점수 49.4로 2위 유지 + 배지)

- 검증: `test_assign.py` 33항목 · `test_serve.py` 32항목 전부 통과, `48셀_검수.md` 재생성 완료.
- **C의 시급성은 A·B로 크게 낮아졌다.** 라벨이 종목을 삭제하는 스위치가 아니게 됐으므로,
  이제 남은 영향은 ① 화면 표시 정직성 ② 5.8% 사용자에서의 순위 강등 ③ 점수 보정(강도 2단계 차이)뿐이다.

## 3. '고' 10종목 — 대표값 재검토표

`강도근거` 컬럼에 적힌 문구를 그대로 옮겼다. **파일 안에 이미 낮은 값이 적힌 종목이 있다.**

| 종목 | 현재 대표 | 현재 근거 문구 | 검토 의견 |
|---|---|---|---|
| 줄넘기 | 11.0 | Rope skipping, general 11.0 | 천천히 뛰는 항목이 별도로 존재. **확인 필요** |
| 등산 | 7.8 | Backpacking/hiking **with daypack** 7.8 | 배낭 종주 기준. 일반 등산·둘레길은 더 낮다. **확인 필요** |
| 농구 | 7.5 | Basketball, **general** 7.5 | 경기 기준. 슛 연습 항목이 따로 있다. **확인 필요** |
| 달리기 | 7.5 | Jogging, general 7.5 (marathon 13.3) | 조깅은 본래 고강도. **유지 타당** |
| 인라인스케이트 | 7.5 | In-line skating 7.5 | 여가 수준 항목 확인 필요 |
| 축구·풋살 | 7.0 | Soccer, **casual** 7.0 (competitive 9.5) | **이미 낮은 쪽을 골랐다. 유지** |
| 자전거 | 7.0 | Bicycling, general 7.0 **(leisure 4.0**, mountain 8.5) | **파일 안에 4.0이 있다.** 다만 종목군이 사이클·MTB를 포함해 단순 교체는 어렵다 — §4 참조 |
| 빙상 | 7.0 | Skating, ice, **general** 7.0 | 여가 스케이팅은 더 낮다. **확인 필요** |
| 테니스+정구 | 6.8 | Tennis, **moderate effort** 6.8 | 복식·랠리 기준 항목 확인 필요 |
| 암벽등반 | (없음) | Rock climbing **5.0-10.5 (대표값 미확정)** | **대표값이 없는데 '고'가 붙어 있다.** 일관성 문제. 확인 필요 |

**제가 임의로 숫자를 바꾸지 않은 이유**: 이 프로젝트는 근거를 "누가 그렇게 생각했다"가 아니라
**"어느 문서 어디에 그렇게 쓰여 있다"** 로 두기로 했다(`근거자료_운동처방.md`). 저장소에 Compendium
원본이 없어 새 값을 인용 형태로 확정할 수 없다. 값을 채우려면 아래 §5의 절차가 필요하다.

## 4. 종목군 병합이 만드는 구조적 한계

우리 종목은 원 조사의 **통합군**이라 하나의 MET으로 대표시키기 어려운 것이 섞여 있다.

| 종목군 | 안에 섞인 것 | MET 폭 |
|---|---|---|
| 자전거, 사이클, 산악자전거 | 동네 라이딩 ↔ 로드 사이클 ↔ MTB | 4.0 ~ 8.5 |
| 무도/격투기 그 외 | 초심자 수련 ↔ 유도 실전 | 5.3 ~ 11.3 |
| 빙상(아이스하키, 스케이팅) | 여가 스케이팅 ↔ 아이스하키 | 7.0 ~ 14.0 |
| 수영+아쿠아로빅+수중발레+수구 | 아쿠아로빅 ↔ 수구 | 5.3 ~ 9.8 |
| 에어로빅 | low impact ↔ high impact | 4.8 ~ 8.0 |
| 배구 | 생활배구 ↔ 경기 | 4.0 ~ 8.0 |

**대표값 하나를 고르는 일 자체가 이미 손실이다.** 근본 해법은 `MET_최소` 컬럼을 추가해
**강도를 범위로 표시**하는 것이다(예: `중~고`). 화면에는 "가볍게도, 세게도 할 수 있는 운동이에요"로
나가고, 상한 비교는 **하단** 기준으로 한다 — 살살 할 수 있는 종목을 막지 않기 위해서다.

> 이 변경은 `sport_master.csv`에 컬럼 하나와 `_effective_intensity()` 수정으로 끝난다.
> 다만 **`MET_최소` 값 자체가 §3과 같은 출처 문제를 갖는다.**

## 5. 결정해 주실 것

| # | 선택지 | 필요한 것 |
|---|---|---|
| **가** | **현행 유지** | 없음. A·B로 실질 피해는 이미 제거됨. 라벨은 "열심히 했을 때"로 읽히고 화면에 그렇게 표기 |
| **나** | §3의 '확인 필요' 7종목 대표값 재선택 | Compendium 2024 해당 항목명·값 확인. 제가 후보 항목명을 제시하면 대조만 해 주셔도 됩니다 |
| **다** | §4의 **강도 범위 표시**로 전환 | 나 + `MET_최소` 채우기. 가장 정확하지만 작업량 최대 |

**권고: 데모까지는 '가', 정식 v1에서 '다'.** A·B로 사용자가 겪는 실제 문제는 사라졌고, 남은 것은
표시 정확도인데 이건 **화면 문구로 흡수할 수 있다** — "이 운동은 세게 하면 고강도예요" 같은.
근거 없이 숫자를 바꾸는 것보다, 근거가 확보될 때까지 **라벨의 의미를 정직하게 표기**하는 편이 낫다.

## 6. 미확인 11종목

| 상태 | 종목 |
|---|---|
| `추천가능=Y` — **채우면 바로 쓰임** | 게이트볼 · 족구 · 육상(걷기·달리기 제외) · 댄스스포츠 · 훌라후프 · 낚시 |
| `추천가능=N` — 채울 필요 없음 | [구기 및 라켓류]·[민속 스포츠]·[체력 단련 및 생활 운동]·[레저 스포츠]·[기타 스포츠] 그 외 종목 |

- 코드에서는 이제 **미확인을 '중'으로 간주**한다(`_effective_intensity()`). 모른다는 이유로 상한을
  그냥 통과시키면, 강도를 아는 종목만 잘려나가고 모르는 종목이 그 자리를 차지하는 역전이 생겼기 때문이다.
  (실제로 수정 전에는 상한이 낮은 사용자에게 **'낚시' 한 종목만** 추천되는 사례가 있었다.)
- 화면에는 계속 `주의: 강도 미확인 종목`으로 표기된다.
