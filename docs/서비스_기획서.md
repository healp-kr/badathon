# 서비스 기획서 — Sportstify

**2026-09-04 · v1.0 · 위치 기반 운동 처방·장소·기록 서비스**
*기술 사양은 `앱구현_PRD.md`·`인터페이스_명세.md`가 정본. 이 문서는 서비스 관점만 다룬다.*

---

## 1. 문제

운동을 시작하려는 사람은 매번 같은 세 곳에서 멈춘다.

| 단계 | 흔한 장벽 | 기존 서비스의 대응 |
|---|---|---|
| 무엇을 할까 | 나에게 맞는 종목·강도를 모른다 | 인기 종목 나열, 개인화 근거 없음 |
| 어디서 할까 | 갈 수 있는 시설을 모른다 | 지도 앱은 있지만 추천과 끊겨 있다 |
| 계속할까 | 얼마나 했는지 기준이 없다 | 운동 일지는 처방과 다른 근거를 쓴다 |

**셋이 각각 있지만 이어져 있지 않다는 것이 문제다.** 하나라도 끊기면 사용자는 이탈한다.

## 2. 한 줄 정의 · 타깃

> **나에게 맞는 운동을, 갈 수 있는 곳에서, 실제로 하게 만드는 앱.**

**1차** 종목·강도를 정하지 못한 성인(19~64세) · **2차** 안전한 강도 상한이 중요한
노인(65세 이상) · **비대상** 숙련자

## 3. 서비스 흐름

```
① 무엇을 할까   설문 13문항 → 선호 12유형 × 체력 16세그먼트 → 종목·강도·보완운동
       ↓         (국민생활체육조사 + 국민체력측정통계)
② 어디서 할까   현 위치 → 자치구 → 주변 체육시설 776곳 · 예약 가능 57곳 · 가는 방법
       ↓         (날씨·미세먼지·자외선에 따라 실내 종목을 위로)
③ 했다          한 번 눌러 기록 → 주간 지침 달성률 → 다음 주 안내
       ↺         (기록이 쌓이면 다음 버전의 추천을 보정한다)
```

## 4. 핵심 기능

| # | 기능 | 사용자가 얻는 것 |
|---|---|---|
| F1 | 온보딩 13문항 (3분 이내) | 검사·측정 없이 유형 배정 |
| F2 | 결과 화면 | 기반 활동 / 익숙한 운동 / 새로운 운동 / 제외 종목 / 강도 처방 |
| F3 | 환경 컨텍스트 배지 | 비·미세먼지·자외선을 반영한 표시 순서 조정 |
| F4 | 지도 · 시설 상세 | 거리 · 전화 · 예약 링크 · 역/정류장/주차장 |
| F5 | 운동 기록 | 한 번 눌러 저장, 주간 달성률 즉시 반영 |
| F6 | 하단 탭 (추천·지도·기록) | 세 단계를 한 앱에서 왕복 |

## 5. 차별점 — 왜 우리가 더 나은가

1. **두 축을 쓴다.** 선호(하고 싶은가)와 체력(해도 되는가)을 분리해, 같은 종목이라도
   강도 상한과 제외 종목이 사람마다 달라진다.
2. **처방과 기록이 같은 근거를 쓴다.** 추천 화면의 "중강도 주 150분"이 곧 기록 화면의
   분모다. 둘이 따로 놀면 처방은 장식이 된다.
3. **추천이 장소에서 끝난다.** 종목 추천 → 실제 시설 → 예약 링크까지 한 흐름이다.
4. **학습·GPU·모델서버가 필요 없다.** 파라미터 JSON을 읽어 계산만 하므로 같은 입력은
   항상 같은 결과를 낸다 — 운영 비용이 낮고 결과 추적이 된다.

## 7. 리스크와 대응

| 리스크 | 대응 |
|---|---|
| 체력 유형 정확도 50% 내외 (자가평가 의존) | 단정 표현 금지, 확신도 낮으면 대안 유형 병기, r 검증 루프 |
| 추천 근거가 인과가 아님 | "추천"이 아닌 **"비슷한 분들의 선택"**으로 표기 |
| 외부 API(기상·대기) 실패 | 판정을 "모름"으로 두고 배지만 숨김 — 추천·기록은 정상 동작 |
| 위치 권한 거부 | 지역 직접 선택(S0-b)으로 우회 |
| 시설 데이터 결측 (실내외 60%, 예약 좌표 49%) | 신뢰도 표기, 결과 없음도 정상 상태로 안내 |
